# 🌐 خلاصه‌ساز هوشمند وب‌سایت (ترمینال)

**فارسی** | [English](README.md)

یک ابزار سبک برای ترمینال که محتوای هر صفحه وب را دریافت می‌کند و با کمک هوش مصنوعی از طریق [OpenRouter](https://openrouter.ai) خلاصه می‌کند. خلاصه **به زبان خودِ وب‌سایت** نوشته می‌شود (فارسی، انگلیسی و ...).

## ✨ امکانات

- 🔗 فقط لینک را وارد کنید و در چند ثانیه خلاصه‌ی Markdown بگیرید
- 🌍 تشخیص خودکار زبان سایت و نوشتن خلاصه به همان زبان
- 🧹 حذف اسکریپت، استایل، منو، فوتر، فرم و موارد اضافی قبل از خلاصه‌سازی
- 📰 جداسازی اخبار و اطلاعیه‌های مهم
- 🔁 حلقه‌ی تعاملی: در یک نشست چند سایت را پشت‌سرهم خلاصه کنید
- 🛡️ محتوای سایت به‌عنوان داده‌ی نامطمئن در نظر گرفته می‌شود (مقاوم در برابر Prompt Injection)
- 🔌 سازگار با هر مدلی که در OpenRouter موجود است

## 📦 نصب

</div>

```bash
git clone https://github.com/Ali-salek/ai-website-summarizer-cli.git
cd ai-website-summarizer-cli

python -m venv .venv
source .venv/bin/activate        # ویندوز: .venv\Scripts\activate

pip install -r requirements.txt
```

## ⚙️ پیکربندی

۱. از [OpenRouter](https://openrouter.ai/keys) یک کلید API بگیرید.
۲. فایل نمونه را کپی کنید و مقادیر را پر کنید:

</div>

```bash
cp .env.example .env
```

```env
API_KEY=your_openrouter_api_key_here
MODEL_NAME=openai/gpt-4o-mini
```

<div dir="rtl">

مقدار `MODEL_NAME` می‌تواند هر شناسه‌ی مدل از [فهرست مدل‌های OpenRouter](https://openrouter.ai/models) باشد.

## 🚀 اجرا

</div>

```bash
python main.py
```

<div dir="rtl">

- اگر `https://` را ننویسید، خودکار اضافه می‌شود.
- برای خروج `exit` یا `quit` بنویسید (یا `Ctrl+C` بزنید).

## 🧠 نحوه‌ی کار

۱. **دریافت**: صفحه با `requests` دانلود می‌شود.
۲. **پاک‌سازی**: `BeautifulSoup` بخش‌های غیرمحتوایی را حذف و متن قابل‌خواندن را استخراج می‌کند.
۳. **محدودسازی**: متن به ۸٬۰۰۰ کاراکتر اول محدود می‌شود تا درخواست سریع و ارزان بماند.
۴. **خلاصه‌سازی**: متن از طریق API اُپن‌روتر به مدل انتخابی ارسال می‌شود.

## 🔧 شخصی‌سازی

همه‌چیز در `main.py` است:

| چه چیزی           | کجا                                       |
| ----------------- | ----------------------------------------- |
| سبک و لحن خلاصه   | `SYSTEM_PROMPT` و `USER_PROMPT`           |
| حداکثر طول محتوا  | `content[:8000]` در `get_website_content` |
| میزان خلاقیت      | `temperature` در `make_answer`            |
| حداکثر طول خلاصه  | `max_tokens` در `make_answer`             |

## ⚠️ محدودیت‌ها

- سایت‌هایی که کاملاً با جاوااسکریپت رندر می‌شوند (SPA) ممکن است متن کمی برگردانند یا هیچ متنی نداشته باشند.
- سایت‌هایی که جلوی ربات‌ها را می‌گیرند یا نیاز به ورود دارند قابل دریافت نیستند.
- صفحات طولانی فقط تا ۸٬۰۰۰ کاراکتر اول خلاصه می‌شوند.
- به قوانین هر وب‌سایت و فایل `robots.txt` احترام بگذارید.
- هزینه‌ی استفاده از API بر اساس حساب OpenRouter و مدل انتخابی شماست.
